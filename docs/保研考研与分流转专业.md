# 保研、考研、分流与转专业

资料截至：2026年10月28日。下文分别注明文件适用范围；2027届毕业生推免规则不等于2026级新生毕业时的规则。

## 一、保研先看资格，再看排名

本节依据教务处2026年9月2日公布的[推免工作管理办法（药大教〔2026〕111号）](https://jwc.cpu.edu.cn/b6/b9/c948a243385/page.htm)及其[8页附件](https://jwc.cpu.edu.cn/_upload/article/files/d2/e0/59c3dd274a9195d602a45da67118/e956d96d-a37a-40fa-9cb4-2ba71b96d83c.pdf)。以下为普通规则摘述，完整条件须通读原文；拔尖基地另有相应办法。

| 项目 | 2026年现行文件中的要求 | 原文位置 |
| --- | --- | --- |
| 推荐对象范围 | 应届全日制本科优秀毕业生；第二学士学位和中外合作办学专业学生不在第五条规定的推荐对象范围内 | 第2页第五条 |
| 学业成绩 | 必修课加权总成绩不低于80分 | 第5页第十条第7项 |
| 必修课记录 | 所有必修课期末总评成绩记录中无缺考、不及格（低于60分）记录 | 同上 |
| 选修学分 | 修完所在专业毕业原则上要求的所有选修课学分的60%以上 | 同上 |
| 非英语专业外语 | 本校组织的大学英语六级不低于425；或在校期间雅思不低于6.5且单项不低于6.0；或托福不低于90 | 第5页第十条第8项 |
| 英语相关专业 | 本校组织的英语专业四级不低于65分 | 同上 |
| 其他条件 | 另有思想品德、纪律与学术诚信、健康、正常毕业、重修课程、毕业后计划和体质测试等要求 | 第4—5页第十条 |
| 获资格后 | 必修课再出现不及格、毕业论文终评低于80分、不能按时毕业并取得学位等，可能取消资格 | 第8页第十八条 |

**阅读提醒：**“达到申请条件”与“在名额内取得推荐资格”是两个环节。上表中的80分不是历年录取线。后续文件如有修订，须以参加推免当年的规则为准。

## 二、综合成绩怎样算

依据[《中国药科大学推免生综合成绩计算办法》（药大教函〔2026〕57号）](https://jwc.cpu.edu.cn/b6/bb/c948a243387/page.htm)及其[7页附件](https://jwc.cpu.edu.cn/_upload/article/files/77/89/6fe2f2f64919a89df8aaf5be5a36/7a0aabea-5110-4c28-9938-7484f513ce75.pdf)：

> 综合成绩＝学习成绩×90%＋综合素质测评成绩×5%＋全面发展评价。

全面发展评价最高累计5分。它与“综合素质测评成绩”是不同项目，不能把两者混为一谈。

学习成绩计算有几个需要提前注意的细节：

1. 四年制看第一至第三学年，五年制看第一至第四学年；纳入所有类型的必修课，非百分制必修课不计入。
2. 按课程学分加权，使用首次获得的课程成绩；缓考科目以60分计入。
3. 转专业学生同一成绩不重复计算；已按学籍规定转换的必修课，只计算参加推免当年6月1日前完成转换的课程，以及转专业前所有未转换的必修课成绩。
4. 综合素质测评按在校期间平均成绩计算；文件对五年制另有参照操行分计算的说明。

**计算示例（仅为演示，不是往年学生数据）：**学习成绩90、综合素质测评90、全面发展评价2分，则综合成绩为90×0.9＋90×0.05＋2＝87.5分。

## 三、科研、竞赛等加分如何理解

以下是2026年计算办法附件第3页表1的摘要，不是完整认定说明。

| 项目 | 文件列示分值或限制 |
| --- | --- |
| 国家级科技类、创新创业类竞赛一等奖/金奖第一完成人 | 3分 |
| 同类二等奖/银奖第一完成人 | 2分 |
| 同类三等奖/铜奖第一完成人 | 1分 |
| 团体奖非第一完成人且排前五 | 按相应分值减半 |
| SCI、EI、ISTP、SSCI论文及国家授权专利 | 第一作者/发明人0.5分/篇（件）；发明专利以外的其他授权专利0.25分/件，须同时满足备注条件 |
| 国内核心期刊科研论文第一作者 | 0.3分/篇 |
| 在读期间入伍后正常退役 | 0.5分；荣立三等功及以上另加0.5分 |
| 国际组织实习 | 0.5分，多次经历不累计；组织界定依文件 |

认定时还要同时核对：同一项目取最高分、不累计；竞赛大项累计不超过3项；科研成果大项累计不超过3项；正式见刊、作者顺序、成果与专业相关性、第一完成单位和原始实验记录等要求。综述及其他类型论文按相应分值减半。与亲属或其他利益相关者（不含指导教师）合作的科研成果不纳入加分认定。

竞赛名录参考表位于附件第4—7页，共80项，不能用其他竞赛替代。**进入名录不等于任何级别获奖都会加分**，仍须结合奖项等级、个人排序和审核结果。建议先向学院确认认定口径，再投入大量时间。

## 五、保研接收与考研

推荐资格由本科所在学校遴选；接收院校还会开展资格审核和考核。夏令营、预报名或学院考核通过后，仍要按当年国家推免系统及目标学校通知完成程序。

例如[药学院2027年接收推免生预报名通知](https://yxy.cpu.edu.cn/b3/7b/c11892a242555/page.htm)分别列出学术学位、专业学位及直博接收专业；其中100700药学一级学科限定符合该通知要求的本校“3+1+X”项目学生报名，不能把它理解为所有学生通用入口。

**考研准备建议（编辑分析）：**先明确研究方向，再选择院校、学院、学术/专业学位与具体专业代码。随后核对当年的招生目录、初试科目、考试大纲、参考书、复试要求及专业背景限制。本文不把往年科目组合写成各专业固定考研科目，也不承诺任何跨专业报考必然被接受。

四年制学生可在大二开始比较方向，大三根据已公布文件建立目标清单；五年制按培养安排调整。时间安排只是规划建议，报名、考试及推免确认时间应逐年核对。

## 七、跨大类转专业：报名与录取分开看

依据[2025级转专业通知（2026年3月27日）](https://vr.cpu.edu.cn/94/c2/c851a234690/page.htm)和[补充通知（2026年4月14日）](https://vr.cpu.edu.cn/97/e1/c851a235489/page.htm)：

- 每人最多填报2个专业志愿，学生只能跨招生大类填报专业。
- 有申请对象、身体条件、处分、学术诚信等条件；特色培养计划、特殊招生类型、中外合作等情况须逐条核对。
- 对因学籍异动编入2025级的学生，补充通知另作说明，应与原通知一起阅读。
- 各学院按接收计划和考核办法选拔，第二志愿录取在第一志愿未录满的专业开展。
- 获批后可能需要补修新专业必修课；录取公示后学校不再接受转回原专业申请；下一学年按转入专业学习并缴费。

“零门槛”是招生问答中的概括性表述，实际办理需同时满足正式通知的对象、条件与考核要求。[各学院实施细则查询通道](https://vr.cpu.edu.cn/88/0c/c885a231436/page.htm)已提供8个学院入口；[考核安排](https://vr.cpu.edu.cn/9b/41/c885a236353/page.htm)也显示学院考核形式存在区别。

**行动建议：**先核对资格，再比较新旧培养方案和需要补修的课程，最后评估目标专业的考核、名额、学费及自身兴趣。不要只为预期保研优势而转专业，尚未核验的比例不足以支撑这种判断。
