# 特色班选拔与基地培养

[← 首页](../README.md) · [专业目录](专业目录.md) · [保研与分流](保研考研与分流转专业.md)

资料截至2026年10月29日。本文以**2025级**校内选拔通知为实例，帮助理解报名、入班与基地培养的衔接。该次报名已结束，以下安排不代表2026级或以后年级的招生承诺。

## 先分清三个环节

| 环节 | 2025级通知中的安排 |
| --- | --- |
| 申请拔尖创新班 | 面向符合条件的2025级普通类本科生，涵盖药学、中药学、生物制药；选拔规模不超过30人 |
| 选拔后修读 | 建议大一第二学期提前跟班修读并参加考核；大二第一学期正式进入拔尖创新班 |
| 进入拔尖基地 | 在大三学年前，从拔尖创新班学生中择优选拔 |

依据：[《关于开展2025级拔尖创新班学生选拔工作的通知》](https://mhc.cpu.edu.cn/88/f6/c10113a231670/page.htm)，2025年12月29日发布。“拔尖创新班”与“基础学科拔尖学生培养计划2.0基地”在通知中是不同选拔环节；其他特色班也须按自身文件确认培养身份。

## 2025级报名与考核实例

| 项目 | 该次通知的规定 |
| --- | --- |
| 成绩门槛 | 第一学期所有必修课程加权成绩在本专业（大类）前50%以内，无不及格记录 |
| 体育与体测 | 第一学期体育及国家学生体质健康标准测试合格；保健课学生另有申请和认定办法 |
| 选科与体检 | 高考选科至少含物理、化学、生物之一；同时符合原文体检等条件 |
| 指定课程 | 按通知修读、参加考核，每门成绩不低于75分；入班后指定课程以必修课成绩计入成绩单 |
| 初试 | 综合学业测试：化学基础占35%，其他学业测试占65%；按1:2择优确定复试名单 |
| 复试及其他测试 | 综合素质面试、体质测试及心理测试，具体考查范围见原文 |
| 选拔成绩 | 综合学业测试×50%＋综合素质测试×40%＋体质测试×10% |
| 该次报名截止 | 2026年1月19日20时，已结束 |

以上为摘要，尚有思想品德、普通类招生资格、不得转专业情形等完整条件。成绩达到门槛后仍需参加选拔；30人是该次总计划上限，不是每个专业各30人。

## 入班后的课程与学籍衔接

该通知要求入选学生在大一第二学期继续完成原专业（大类）课程并参加原学院大类分流；大一奖学金、荣誉评选由转出学院处理。部分已修课程按教务处通知认定学分，不能认定的课程需要补修并按规定缴费；同时须服从集中住宿安排。

选班前可以把原专业课表、目标班课表和学分认定办法放在一起比较，确认实验、科研训练及补修负担。这是个人规划建议，具体办理以本年级通知为准。

## 基地推免如何阅读

基地推免的适用对象、75分学业条件、科研与素养要求、240分综合测评以及审核程序，见[保研专题第八节](保研考研与分流转专业.md#八拔尖基地的推免条件要单独核对)。原文为[药大教〔2025〕143号及附件](https://mhc.cpu.edu.cn/75/7a/c11388a226682/page.htm)。普通专业和未纳入基地培养的学生，应另外核对自己适用的制度。
