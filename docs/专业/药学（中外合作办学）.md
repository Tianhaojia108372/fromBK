# 药学（中外合作办学）

[← 专业目录](../专业目录.md) · [首页](../../README.md) · [保研与分流](../保研考研与分流转专业.md) · [本专业课程表](../2025级课程摘录索引.md#courses-10)

> 中外合作办学 · 资料截至：2026年10月28日

2025级方案第67—69页列示四年制、理学学士，毕业最低142学分，包含生化与药理方向课程。2026招生问答说明合作方为英国斯特拉斯克莱德大学，采取“3+1”培养安排。能否赴外及取得双方证书，须满足语言、课程与学位要求；不要把项目名称当成无条件双学位承诺。

2025级表中必修课名称举例：Introduction to Pharmacology、Introduction to Biochemistry、Biomedical Biochemistry、Advanced Pharmacology、Clinical Pharmacology、药剂学。英文课程保留原表名称，不自行替换为其他专业的中文课名；具体安排见[原方案第69页](https://jwc.cpu.edu.cn/_upload/article/files/ae/f7/30b87a2345419428f11685def39c/cf4a9025-0e88-465f-9ab5-4b297f78deec.pdf#page=69)。

**选择分析：**适合希望接受英语环境训练、认真考虑国际培养且能评估经济成本的同学。需要把国外学费、生活费、汇率、语言条件及毕业安排一起比较，不能只比较国内年度学费。


**推免与费用：**请同时阅读[完整合作培养说明](../../中国药科大学专业选择指南_第1版.md#international)，核对推免范围、国内学费及境外费用。
