# 临床药学（中外合作办学）

[← 专业目录](../专业目录.md) · [首页](../../README.md) · [保研与分流](../保研考研与分流转专业.md) · [本专业课程表](../2025级课程摘录索引.md#courses-15)

> 中外合作办学 · 资料截至：2026年10月28日

2025级方案第92—95页列示五年制、理学学士，毕业最低157学分。合作方为英国曼彻斯特大学，采用“2+2+1”，即前两年国内、第三四年国外、第五年回校临床实习，赴外须满足对方入学条件。课程及学位要求见[方案第92—95页](https://jwc.cpu.edu.cn/_upload/article/files/ae/f7/30b87a2345419428f11685def39c/cf4a9025-0e88-465f-9ab5-4b297f78deec.pdf#page=92)。

**选择分析：**除经济和语言因素外，还应比较是否接受五年本科、跨国学习与临床实践安排，以及自己最终希望在哪个地区继续学习或就业。

**推免与费用：**学校2026年推免管理办法第五条将中外合作办学专业排除在该条推荐对象范围外。2026年收费公示列示合作项目国内期间学费为26400元/生·学年，境外费用需另查项目与合作院校当年说明。来源：[推免办法](https://jwc.cpu.edu.cn/b6/b9/c948a243385/page.htm)、[收费公示](https://jcc.cpu.edu.cn/_t910/b6/84/c4692a243332/page.htm)。


**推免与费用：**请同时阅读[完整合作培养说明](../../中国药科大学专业选择指南_第1版.md#international)，核对推免范围、国内学费及境外费用。
